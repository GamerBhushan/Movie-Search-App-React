# Movie-Search-App-React ![Build Status](https://img.shields.io/badge/status-active-brightgreen)

## ✨ Developed by Bhushan  
A fast and seamless **Movie Search App** built with **React, Vite & TypeScript**. It provides real-time movie search with a simple and responsive UI.

---

## 🚀 Features

- 🎬 Search for movies in real-time.
- ⚡ Fast performance with **Vite**.
- 🔧 Built with **TypeScript** for better type safety.
- 🎨 Fully responsive UI.
- 🛠️ API integration with [OMDb API](https://www.omdbapi.com/).

---

## ⚡ Tech Stack

- **Frontend:** React + Vite + TypeScript
- **CSS Framework:** Tailwind CSS (or any other framework if used)
- **API:** [OMDb API](https://www.omdbapi.com/)

---

## 🛠️ Installation & Setup

Follow these steps to run the project locally:

### 1 **Clone the Repository**
```sh
npm install -g bun
git clone https://github.com/GamerBhushan/Movie-Search-App-React.git
cd Movie-Search-App-React
```

### 2 **Install Dependencies**
```sh
bun install  
```

### 3 **Set Up API Key**
- Create an account on [OMDb API](https://www.omdbapi.com/) and get your API key.
- Create a `.env` file in the root directory and add:
  ```sh
  VITE_MOVIE_API_KEY=your_api_key_here
  ```

### 4 **Run the Project**
```sh
bun run dev  
```
- The app will start on **`http://localhost:5173/`** (default Vite port).
